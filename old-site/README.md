# Old Turbify files go here

Put **all** of the files you saved from your old Turbify site in this folder.
Keep their original names and subfolders. Don't edit them here: this folder is
the "original copy" we work from, so you can always look back at it.

Turbify (formerly Yahoo Small Business / Yahoo Sitebuilder) backups usually
contain one of these:

- **`.html` / `.htm` files plus images.** This is the published website. We can
  reuse it directly.
- **A Sitebuilder project (files ending in `.sbs`, or a folder of page and
  template files).** That is the editor's project format, not a website.
  Look inside for a folder of exported `.html` pages, or we can rebuild the
  pages by hand from screenshots and text.
- **A `.zip` file.** Unzip it first, then upload what's inside.

Not sure which one you have? Upload it anyway and we'll work it out.

See the main [README](../README.md), step 1, for how to upload files.
